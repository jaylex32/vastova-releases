# Vastova

**Fast, verified delivery of big files and whole folders, straight from one computer to another.**

No accounts, no size limit, nothing in between: Vastova sends files directly between computers over encrypted connections. Transfers resume by themselves after a dropped connection, every chunk is checked as it arrives, and a link opens in any browser.

## Download

Open the **[latest release](https://github.com/jaylex32/vastova-releases/releases/latest)** and pick the file for your system:

| System | File |
| --- | --- |
| Windows 10/11 | `Vastova_<version>_x64-setup.exe` (or the `.msi`) |
| macOS, Apple silicon (M1 and later) | `Vastova_<version>_aarch64.dmg` |
| macOS, Intel | `Vastova_<version>_x64.dmg` |
| Linux | `.AppImage` (any distribution), `.deb` (Ubuntu, Debian) or `.rpm` (Fedora, openSUSE) |

Vastova updates itself after that.

### The first time you open it

- **Windows** may show "Windows protected your PC". Click **More info**, then **Run anyway**.
- **macOS** may say the app can't be opened. Right-click Vastova in Applications, choose **Open**, then confirm.

These warnings appear because the installers aren't signed with a paid certificate yet. You can check a download against `SHA256SUMS.txt` in each release.

## What it does

- Send and receive files and folders of any size, resumable and verified.
- Links that open in any browser (`https://vastova.pages.dev/#…`), or hand over to the app for full speed.
- Cloud links through your own S3-compatible storage, so recipients can download while you're offline.
- Contacts, portals (a link anyone can use to send you files), shared folders and automations.
- Windows, macOS and Linux.

## Privacy

Your files never pass through a Vastova server. There are no accounts, no tracking and no analytics.
